# Amalka Dewmini — Portfolio

Personal portfolio website of **Amalka Dewmini**, a BSc (Hons) Software Engineering undergraduate at Sri Lanka Technology Campus (SLTC) with a focus on Quality Assurance, test automation and web development.

**Live site:** https://dewmini1212.github.io/portfolio/

---

## Sections

- **Home** – introduction with quick links to About and the CV download
- **About** – who I am, my interests and my approach to quality
- **Education** – academic background
- **Skills** – languages, web technologies, testing tools, databases and data analysis
- **Projects** – six selected projects with descriptions, tech stacks and GitHub links
- **Certifications** – seven certificates (Simplilearn, HackerRank, CoDeKu DevOps Academy) that open in a new tab
- **Contact** – email, GitHub and LinkedIn links, plus a contact form

## Built with

- HTML5 and CSS3 (custom properties, grid and flexbox)
- Vanilla JavaScript (scroll animations, active navigation, certificate viewer)
- [Poppins](https://fonts.google.com/specimen/Poppins) from Google Fonts

No frameworks and no build step. The page is a single self-contained `index.html`.

## Features

- Responsive layout for desktop, tablet and mobile
- Dark theme with a teal glow background
- Scroll-reveal animations that respect the reduced-motion setting
- Download CV button
- Certificates and the photo are embedded in the page, so it works offline

## Project structure

```
portfolio/

```

## Run locally

1. Clone the repository
   ```bash
   git clone https://github.com/dewmini1212/portfolio.git
   ```
2. Open `index.html` in any browser. There is nothing to install.

## Deploy with GitHub Pages

1. Push the repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select **main** and **/ (root)**.
4. Save. The site goes live after a minute or two.
